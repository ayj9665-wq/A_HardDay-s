# 수동 QA 체크리스트

CI가 확인하는 것은 두 OS에서 테스트, 타입 빌드, clippy, 데스크톱 링크 단계가 통과한다는 것까지입니다.
아래 항목은 실제 OS에서 앱을 띄워야만 확인되므로, 릴리스마다 Windows와 macOS에서 각각 수행하고 결과를 기록합니다.

기록 형식: `날짜 · 버전 · OS · 통과/실패 · 비고`

## 1. 실행과 창

- [ ] 앱이 뜨고 시계가 현재 시각을 가리킨다
- [ ] 제목 영역을 끌어 창이 움직인다
- [ ] 최소화 · 최대화 · 닫기가 동작한다
- [ ] 창 버튼이 macOS에서는 좌상단, Windows에서는 우상단에 있다
- [ ] 창 가장자리를 끌어 크기를 조절할 수 있고, 최소 크기(420×520)에서 잘리는 곳이 없다
- [ ] 항상 위 고정을 켜면 다른 창 위에 남는다

## 2. 배경 모드

- [ ] `clear` 모드에서 배경이 실제로 비친다 — macOS는 `macOSPrivateApi`가 켜져 있어야 동작합니다
- [ ] `solid`로 되돌리면 종이색 배경이 돌아온다

## 3. 앱 연동과 작업 시간 — 이 앱의 핵심

- [ ] APPLICATION TRIGGER 목록에 실행 중인 앱이 나온다
- [ ] macOS 목록에 Dock에 뜨는 앱만 보이고, 헬퍼나 데몬은 없다
- [ ] 목록의 두 번째 줄이 채워져 있다 — Windows는 창 제목, macOS는 번들 식별자
- [ ] 이 앱 자신은 목록에 없다
- [ ] 앱을 연결하고 그 앱으로 전환하면 **작업 시간이 실제로 증가한다**
- [ ] 연결하지 않은 앱으로 전환하면 시간이 멈춘다
- [ ] 이 앱으로 돌아오면 시간이 멈춘다
- [ ] 같은 앱 안에서 창만 바꿀 때는 추적이 끊기지 않는다

## 4. 데이터

- [ ] 할 일을 추가하고 앱을 껐다 켜면 그대로 남아 있다 — `crypto.randomUUID` 부재 시에도 추가가 실패하지 않아야 합니다
- [ ] 작업 시간이 재시작 후에도 유지된다

## 5. Medicine 화면

- [ ] 파일 선택으로 이미지를 넣을 수 있다
- [ ] 파일 탐색기/Finder에서 이미지를 끌어다 놓을 수 있다
- [ ] 브라우저에서 이미지를 끌어다 놓을 수 있다 — 실패하면 어떤 URL이었는지 기록
- [ ] 붙여넣기(⌘V / Ctrl+V)로 이미지를 넣을 수 있다
- [ ] 레이어를 선택하고 삭제 키로 지울 수 있다 — Mac 키보드의 큰 삭제 키 포함
- [ ] 색상을 클릭하면 클립보드에 복사된다
- [ ] 추천 트랙을 누르면 기본 브라우저에서 YouTube Music이 열린다

## 6. 저장

- [ ] 스냅샷 버튼으로 PNG를 저장할 수 있다
- [ ] 저장된 PNG가 Retina/HiDPI 화면에서 선명하다
- [ ] `clear` 모드에서 저장한 PNG의 배경이 투명하다

## 7. 배포본

- [ ] 설치 패키지에 아이콘이 붙어 있다
- [ ] **다른 물리 기기**로 옮겨 실행된다
- [ ] 서명을 적용했다면 경고 없이 열린다 (`spctl -a -vv "A Hard Day's.app"`)
- [ ] macOS 유니버설 빌드가 Intel Mac에서도 실행된다

## 아직 확인되지 않은 항목

다음은 정적 분석에서 위험으로 지목했지만 실행으로 확인된 적이 없습니다. 위 항목을 수행하면서 결과를 기록하고,
문제가 재현되면 해당 항목의 해결을 별도로 진행합니다.

| 항목 | 위험 | 확인 지점 |
| --- | --- | --- |
| 보안 컨텍스트 | macOS 웹뷰가 보안 컨텍스트가 아니면 `navigator.clipboard`가 없다 | 5장 색상 복사 |
| 원격 이미지 fetch | 웹뷰 출처가 OS마다 달라 CORS 결과가 갈릴 수 있다 | 5장 브라우저 드롭 |
| fs 권한 범위 | 대화상자가 고른 경로가 fs scope 밖이면 저장이 거부된다 | 6장 PNG 저장 |
| 장식 없는 창 | macOS에서 가장자리 리사이즈와 그림자 거동 | 1장 창 |

devtools 콘솔에서 다음을 확인하면 첫 두 항목의 원인을 바로 좁힐 수 있습니다.

```js
window.isSecureContext
typeof crypto.randomUUID
typeof navigator.clipboard
location.origin
```
